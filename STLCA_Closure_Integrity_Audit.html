How to read this
If an agency marks records Closed or Completed, the public deserves proof that closure corresponds to documented inspection activity. This dashboard does not claim wrongdoing by itself. It quantifies whether basic verification fields exist in the dataset you load. If the integrity rate is low, the correct response is not spin. The correct response is audit and remediation.
